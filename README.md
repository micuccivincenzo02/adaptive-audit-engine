# Adaptive Audit Engine IT/CH — Case Study

Case study page for a solo build: an engine that reads a contract and an invoice side by side and explains, in plain language, where the numbers stop matching (Italian and Swiss VAT, rounding, EUR/CHF).

- Stack: Python 3.11, Claude Vision API, Pydantic, Streamlit, pytest (215 tests)
- Screenshots use synthetic invoices and a synthetic contract — no real client data.

Live page: https://micuccivincenzo02.github.io/adaptive-audit-engine/
